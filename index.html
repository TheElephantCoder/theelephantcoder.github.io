bit-compact

Zero-dependency Rust engine for SQ8 scalar quantization. 4× smaller embeddings, zero-alloc seeks.

A low-level multimodal embedding store — 32B Big-Endian header, per-dimension calibration, Send + Sync reader, 10 APIs, and a self-contained serve GUI. Built for concurrent analytical scans with cache-line and disk-block awareness.

  • 4× reduction · f32 → u8 · SQ8 linear quantization
  • 1 seek · zero-allocation random access
  • Dockerized, stripped binary · tini runtime

NexUSB

Professional bootable USB rescue toolkit. 150+ utilities, one stick.

Boots a live Linux environment for malware scanning, data recovery, disk work, networking, and remote access. Two builds — minimal (~2GB) and full (~32GB) — with GTK GUI and per-category text menus. Builds on Linux, Docker, or WSL2.

  • ClamAV, TestDisk, GParted, Wireshark, nmap, Remmina, chntpw
  • UEFI + Legacy BIOS, Secure Boot-aware GRUB
  • Multi-partition layout: boot / live / Windows / ISOs

claw-security-auditor

Autonomous auditor for OpenClaw skills. Static only — never executes untrusted code.

Scans installed skills for shell execution, remote code download, file deletion, exfiltration, obfuscation, and 38 more patterns. Assigns a 0–100 risk score, risk level, and generates mitigation recommendations. Dashboard at localhost:7777 with no build step.

  • H1–H16 high · M1–M20 medium · L1–L10 low + entropy (H4e)
  • CLI: --output json|markdown|csv · --fix · --compare · --trust
  • Zero dependencies, read-only, file watcher
