# TheElephantCoder Portfolio

A modern, professional portfolio website showcasing projects and skills.

## 🚀 Features

- **Modern Design**: Built with professional UI components inspired by shadcn/ui, KokonutUI, and Uiverse
- **Responsive**: Fully responsive design that works on all devices
- **Animated**: Smooth animations and transitions throughout
- **Interactive**: Hover effects, scroll animations, and parallax backgrounds
- **GitHub Pages Ready**: Optimized for deployment on GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3 (Modern features: Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
- Lucide Icons
- Inter Font (Google Fonts)

## 📦 Deployment to GitHub Pages

### Option 1: Direct Deployment

1. Push this repository to GitHub
2. Go to repository Settings → Pages
3. Under "Source", select your branch (usually `main`)
4. Select folder: `/ (root)`
5. Click Save
6. Your site will be available at: `https://TheElephantCoder.github.io/repository-name/`

### Option 2: Custom Domain

1. Add a `CNAME` file with your custom domain
2. Configure DNS settings with your domain provider
3. Enable HTTPS in GitHub Pages settings

## 🎨 Customization

### Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary: #6366f1;
    --secondary: #8b5cf6;
    --accent: #06b6d4;
    /* ... more colors */
}
```

### Content

- Update project information in `index.html`
- Modify sections as needed
- Add or remove projects in the Projects section
